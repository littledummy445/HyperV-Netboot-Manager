# SECURITY.md

## Reporting a Vulnerability
If you discover a security vulnerability within **HyperV-Netboot-Manager**, please report it responsibly. Do not disclose security-related issues publicly until they have been addressed.

* **Contact**: Submit security concerns via private communication or open a private advisory on the GitHub repository.
* **Response Timeline**: Acknowledgment of vulnerability reports typically occurs within 48 hours.
